# API for Kern CMS

API support bundled with [Kern CMS](https://github.com/binhtq1/kern-cms).

[Source](https://github.com/binhtq1/kern-cms/tree/main/platform/packages/api) · [Issues](https://github.com/binhtq1/kern-cms/issues) · [MIT license](LICENSE)

## Installation

This package is resolved from the local path repositories in the Kern CMS checkout.
Install the project's locked dependencies from the repository root:

```shell
composer install
```

## Documentation

See the [API configuration](config/api.php), [routes](routes), and this README for package documentation.

Authentication: [Laravel Sanctum documentation](https://laravel.com/docs/sanctum).

# Available API

- See the list in `http://your-domain.com/docs/index.html`
